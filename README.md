# SellerShield AI

SellerShield AI is an autonomous, policy-governed customer support agent for online sellers. It resolves routine post-purchase requests end to end through deterministic policy evaluation, strict fact verification, and human-in-the-loop approvals—ensuring money safety, auditability, and verifiable truth across every interaction. Refund guardrails rely on strict integer paise arithmetic (eliminating fractional rounding drift) and return policies are validated against exact Asia/Kolkata (IST) calendar-day boundaries.
