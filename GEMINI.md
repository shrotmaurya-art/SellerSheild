- Use Planning mode only for tasks marked COMPLEX or PLANNING. Show the implementation plan and wait for approval before editing.
- Never run two agents on the same folder at the same time.
- Terminal: ask before any command that deletes files, installs software, touches git remotes, or pushes. Never push.
